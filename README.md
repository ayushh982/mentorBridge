# MentorBridge

A full-stack MERN mentorship platform that connects students with experienced mentors for one-on-one guidance, secure payments, real-time chat, AI assistance, and video calling.

## Live Demo

🌐 Frontend:
https://mentorbridge-ecru.vercel.app/

⚙️ Backend API:
https://mentorbridge-backend-bdla.onrender.com/

## Features

- JWT Authentication
- Student Dashboard
- Mentor Dashboard
- Admin Panel
- Mentor Verification
- Session Booking
- Razorpay Payment Gateway
- Real-time Chat (Socket.IO)
- One-to-One Video Calling (ZegoCloud)
- AI Assistant (Google Gemini)
- Reviews & Ratings
- Responsive UI

## Tech Stack

Frontend
- React
- Vite
- Tailwind CSS

Backend
